# Tears of the Kingdom Manual APWorld

This is an Archipelago Manual for The Legend of Zelda: Tears of the Kingdom that involves using a custom save file and [Marc Robledo's save editor](https://www.marcrobledo.com/savegame-editors/zelda-totk/) to adjust the inventory and flags in a playthrough as you send and receive items.

Due to the information being somewhat extensive, all setup and playthrough instructions can be found [here.](https://docs.google.com/document/d/1EsrK6XNu0aqclyG3LYDWbxI8_zfmTqAnRkCijalOqfA/edit?usp=sharing)
